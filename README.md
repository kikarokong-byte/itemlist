# ใบเบิกพัสดุ (แบบฟอร์มกรอกออนไลน์)

แบบฟอร์มใบเบิกพัสดุที่กรอกบนเว็บได้ จัดหน้าตามแบบหนังสือราชการ (ระเบียบงานสารบรรณ) และพิมพ์ลง A4 ได้ 1 แผ่น

- เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร
- ขอบกระดาษ: บน 2.5 ซม. ซ้าย 3 ซม. ขวา 2 ซม. ล่าง 2 ซม. · ย่อหน้า 2.5 ซม.
- ฟอนต์ Sarabun (แบบเดียวกับ TH Sarabun New) ขนาดเทียบเท่า 16 พอยต์ พิมพ์เป็นสีดำทั้งหมด
- ตัวเลขไทยเป็นค่าเริ่มต้น เปิด/ปิดได้ที่ปุ่ม "เลขไทย"
- ใส่ตราหน่วยงานและชื่อส่วนราชการได้ (ไม่บังคับ ถ้าว่างจะไม่พิมพ์)
- ช่องลงนามแบบราชการ: ลงชื่อ / (ชื่อเต็ม) / ตำแหน่ง
- วันที่ใช้ปี พ.ศ. และตั้งเป็นวันนี้ให้อัตโนมัติ
- ตารางรายการ เพิ่ม/ลบแถวได้ กด Enter เพื่อไปแถวถัดไป ถ้าเกินหนึ่งแผ่นหัวตารางจะพิมพ์ซ้ำ
- บันทึกร่างไว้ในเบราว์เซอร์อัตโนมัติ
- "คัดลอกรายการ" คัดลอกตารางไปวางใน Excel / Google Sheets ได้
