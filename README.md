# ใบเบิกพัสดุ (แบบฟอร์มกรอกออนไลน์)

แบบฟอร์มใบเบิกพัสดุที่กรอกบนเว็บได้ จัดหน้าเหมือนฟอร์มกระดาษ และพิมพ์ลง A4 ได้ 1 แผ่น

- เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร
- วันที่ใช้ปี พ.ศ. และตั้งเป็นวันนี้ให้อัตโนมัติ
- ตารางรายการมีอย่างน้อย 20 แถว เพิ่ม/ลบแถวได้ กด Enter เพื่อไปแถวถัดไป
- ลำดับ "ที่" รันให้อัตโนมัติเฉพาะแถวที่กรอกแล้ว
- บันทึกร่างไว้ในเบราว์เซอร์อัตโนมัติ
- "คัดลอกรายการ" คัดลอกตารางไปวางใน Excel / Google Sheets ได้
- "พิมพ์ / บันทึก PDF" ซ่อนปุ่มต่าง ๆ แล้วพิมพ์เฉพาะฟอร์ม ช่องลายเซ็นเว้นไว้เซ็นด้วยปากกา
