# ใบเบิกพัสดุ

โปรแกรมกรอกใบเบิกพัสดุทีละหลายรายการ แล้วส่งออกเป็นไฟล์ Word (.docx) ตามแบบฟอร์มเดิม

## วิธีใช้
1. เปิด `index.html` ในเบราว์เซอร์ (ไม่ต้องติดตั้งอะไร ใช้แบบออฟไลน์ได้)
2. กรอกข้อมูลใบเบิก และรายการที่ขอเบิก
   - กด **วางหลายรายการพร้อมกัน** แล้ววางจาก Excel / Google Sheets หรือพิมพ์บรรทัดละรายการ เช่น `กระดาษ A4 80 แกรม 5 รีม`
   - หรือวางข้อมูลหลายบรรทัดลงในช่องไหนของตารางก็ได้
   - Enter = ลงแถวถัดไป, ชื่อรายการที่เคยใช้จะขึ้นให้เลือก พร้อมหน่วยเดิม
3. กด **ส่งออก Word (.docx)**

## รูปแบบเอกสาร
- จัดหน้าตามแบบฟอร์มกระดาษเดิม เปลี่ยนเฉพาะฟอนต์ (TH SarabunPSK / TH Sarabun New / TH SarabunIT๙) และขนาด (ค่าเริ่มต้น 16 พอยต์)
- ช่องที่กรอกแล้วพิมพ์เป็นข้อความธรรมดาแทนเส้นจุด ช่องที่ว่างยังเป็นเส้นจุดไว้เขียนด้วยมือ
- แผ่นละ 20 แถว (ปรับได้) ถ้ารายการเกิน ขึ้นแผ่นใหม่ให้เอง โดยทุกแผ่นมีหัวกระดาษและช่องลงนามครบ เลขแผ่นที่ใส่ให้อัตโนมัติ
- ข้อมูลที่กรอกบันทึกไว้ในเบราว์เซอร์อัตโนมัติ

## สำหรับผู้พัฒนา
แก้ไขที่ `src/app.html` แล้วรัน `python3 build.py` เพื่อสร้าง `index.html` (ฝังฟอนต์ TH Sarabun New จาก `fonts/` สำหรับหน้าตัวอย่าง)
